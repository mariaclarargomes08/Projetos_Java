## 📁 Exercícios

### Calculadora de Operações Básicas
📄 [`src/Exercicios/ProgramaPrincipal.java`](./src/Exercicios/ProgramaPrincipal.java)

Programa simples que lê dois números inteiros informados pelo usuário e exibe o resultado das quatro operações matemáticas básicas: soma, subtração, multiplicação e divisão.

**Conceitos praticados:**
- Entrada de dados via `Scanner`
- Operadores aritméticos
- Formatação de saída com `System.out.println`


### Programa de Estudos sobre Interfaces
📄[Link](ex_Interfaces)

Programa que simula veículos de passeio e SUV. Lê pelo teclado o ID e o combustível inicial de cada veículo, reabastece o tanque respeitando a capacidade máxima (50 L para passeio e 90 L para SUV) e simula o veículo em movimento.

Estrutura: interface `IVeiculo`, classe abstrata `Veiculo` e as classes `VPasseio` e `VSUV`.

**Conceitos praticados:**
- Interfaces
- Classes abstratas e métodos abstratos
- Herança
- Atributos `protected`
- Entrada de dados via `Scanner`
